
# Customer Retention Analytics

## Project Overview
This project analyzes customer churn data to understand why customers leave a subscription service and identify ways to improve customer retention.

## Objectives
- Calculate customer churn and retention rates.
- Estimate Customer Lifetime Value (CLV).
- Identify monthly recurring revenue (MRR) loss.
- Analyze churn by contract type, subscription type, payment method and customer behavior.
- Provide business recommendations to improve retention.

## Tools Used
- Google Sheets
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Charts and Visualizations

## Key Results
- Total Customers: 600
- Churned Customers: 247
- Retained Customers: 353
- Churn Rate: 41.17%
- Retention Rate: 58.83%
- Estimated Average Revenue CLV: ₹30,886.88
- Monthly Revenue Loss: ₹2,40,102.48

## Key Findings
- Month-to-Month contracts have the highest churn rate (59.81%).
- One Year contracts have the lowest churn rate (20.12%).
- UPI has the highest payment-method churn rate (45.07%).
- Net Banking has the lowest payment-method churn rate (37.14%).

## Business Recommendations
- Encourage customers to choose long-term contracts.
- Improve retention strategies for month-to-month customers.
- Investigate payment-related issues.
- Monitor support tickets and late payments.

## Conclusion
This analysis identifies important customer churn patterns and provides data-driven recommendations to improve customer retention and reduce revenue loss.
